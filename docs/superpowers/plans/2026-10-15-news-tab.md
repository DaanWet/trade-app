# News Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Nieuws" tab that shows recent articles about the user's open positions, watchlist tickers and free keywords, with a navbar badge counting new articles (issue #11).

**Architecture:** Two small news sources (`yahooNews` for tickers, `googleNews` RSS for keywords) feed a
`newsService` that stores articles in SQLite (migration 5) and links each one to the followed topics it
is about. The navbar polls `GET /api/news/unread`; that call triggers a background refresh when the last
one is stale. The backend has no timer of its own. The Angular page shows one timeline with filter chips.

**Tech Stack:** Express 5 + better-sqlite3 + zod + yahoo-finance2 v3 + fast-xml-parser 5 (backend,
vitest + supertest); Angular 21 standalone components + signals + Bootstrap 5 (frontend, Karma/Jasmine).

**Spec:** `docs/superpowers/specs/2026-10-15-news-tab-design.md`

## Global Constraints

- Backend source files use **single quotes** and English comments (match `services/providers/*.ts`). Backend tests use **double quotes** (match existing `*.test.ts`).
- Frontend files use single quotes. UI copy and frontend comments are **Dutch**. Templates use `@if`/`@for`, components are standalone.
- `fast-xml-parser` `^5.11.2` goes in **both** `backend/package.json` and root `package.json` at the same installed version. `npm run check:deps` must pass.
- Refresh interval **30 min** (`NEWS_REFRESH_INTERVAL_MS`). Retry after an all-failed round **5 min** (`NEWS_RETRY_AFTER_FAILURE_MS`). Retention **30 days** (`NEWS_RETENTION_DAYS`).
- Yahoo returns **10** news items per query. Google keeps at most **20** items per keyword. The badge polls every **120 000 ms**.
- Google URL: `https://news.google.com/rss/search?q=<encodeURIComponent(keyword + " when:7d")>&hl=nl&gl=BE&ceid=BE:nl`. Node's default `fetch` User-Agent works; this was verified on 2026-10-15 (200, 38 items).
- Ticker topic: uppercased, must match `^[A-Z0-9.^=\-]{1,20}$`. Keyword: trimmed, 2–60 chars. Keywords are unique case-insensitively.
- **A keyword's text never appears in a log message.** Use `keyword #<id>`. Ticker symbols may appear, because Sentry's `scrubText` redacts them.
- **No test touches the network.** Providers are mocked with `vi.mock`, and Google's `fetch` is stubbed.
- **Commits:** each task ends with a `wip(news): …` commit. Task 9 squashes everything (spec + plan included) into **one** commit, per the user's one-feature-one-commit rule. Per the user's CLAUDE.md, **no `Co-Authored-By` line**. Do not push.
- Before Task 1, record the base commit: `git rev-parse HEAD` (expected `0cb78e7`). Task 9 squashes onto it.

## Review Focus

1. **Opening the tab while a background round is running** (e.g. right after app start, when the badge poll has just kicked one off). The page must show the result once the round finishes, not an empty list that never updates. The page joins the round via `POST /refresh` (Task 8 test).
2. **Pressing ⟳ halfway through a visit.** Articles that were `NIEUW` when the tab opened must keep their label; the server has already marked them seen. The page keeps a visit-scoped set of new ids (Task 8 test).
3. **A stale or out-of-order `seen_at`** (an older response echoed late). It must not move `news_last_seen` backwards and bring back old "new" labels and badge counts. The server ignores older values (Task 5 test).
4. **The same keyword typed in another case or with spaces** ("ECB rente" vs " ecb RENTE"). This must be a 409, not a second chip. Handled by trim + `COLLATE NOCASE` (Task 3 and Task 5 tests).
5. **Google answering 200 with a non-RSS page** (consent wall, HTML). This must count as a failure (warning plus failed topic), not silently produce zero articles (Task 2 test).

```ts
import { yahoo } from '../yahooClient';
import { isRateLimitError, markLimited, markRecovered } from '../rateLimitMonitor';
import type { NewsItem } from './types';

/**
 * Ticker news from Yahoo's search endpoint.
 *
 * Searching by symbol alone is unreliable: `KBC.BR` returns no news while `KBC Group`
 * does, and a short symbol like `CAS` returns articles about unrelated "CAS" companies.
 * So we query by symbol *and* company name, and keep only items Yahoo itself tags with
 * the symbol in `relatedTickers` — the one relevance rule that holds for both cases.
 */

const NEWS_PER_QUERY = 10;

/** Trailing legal-form tokens; with them Yahoo's news search misses (`KBC Group NV` → 0). */
const LEGAL_SUFFIXES = new Set([
  'nv', 'n.v.', 'sa', 's.a.', 'ag', 'se', 'asa', 'ab', '(publ)', 'plc',
  'inc', 'inc.', 'corp', 'corp.', 'corporation', 'co.', 'ltd', 'ltd.', 'limited',
]);

export function cleanCompanyName(name: string): string {
  const words = name.trim().split(/\s+/);
  while (words.length > 1 && LEGAL_SUFFIXES.has(words[words.length - 1].toLowerCase())) {
    words.pop();
  }
  return words.join(' ').replace(/[,\s]+$/, '');
}

interface YahooNewsRaw {
  uuid?: string;
  title?: string;
  publisher?: string;
  link?: string;
  providerPublishTime?: Date | number | string;
  relatedTickers?: string[];
}

function toNewsItem(raw: YahooNewsRaw, symbol: string): NewsItem | null {
  const related = (raw.relatedTickers ?? []).map((t) => t.toUpperCase());
  if (!related.includes(symbol)) return null;
  if (!raw.uuid || !raw.title || !raw.link || raw.providerPublishTime == null) return null;
  const published = new Date(raw.providerPublishTime);
  if (isNaN(published.getTime())) return null;
  return {
    id: raw.uuid,
    title: raw.title,
    publisher: raw.publisher ?? null,
    url: raw.link,
    published_at: published.toISOString(),
    source: 'yahoo',
  };
}

/** Throws only when every query failed, so the caller can count it as a provider failure. */
export async function fetchTickerNews(symbol: string, name: string | null): Promise<NewsItem[]> {
  const sym = symbol.toUpperCase();
  const queries = [sym];
  const cleaned = name ? cleanCompanyName(name) : '';
  if (cleaned && cleaned.toUpperCase() !== sym) queries.push(cleaned);

  const byId = new Map<string, NewsItem>();
  let lastError: unknown = null;
  let failures = 0;
  for (const query of queries) {
    let raws: YahooNewsRaw[];
    try {
      const result = await yahoo.search(query, { quotesCount: 0, newsCount: NEWS_PER_QUERY });
      markRecovered('yahoo');
      raws = (result.news ?? []) as YahooNewsRaw[];
    } catch (err) {
      if (isRateLimitError(err)) markLimited('yahoo');
      lastError = err;
      failures++;
      continue;
    }
    for (const raw of raws) {
      const item = toNewsItem(raw, sym);
      if (item && !byId.has(item.id)) byId.set(item.id, item);
    }
  }
  if (failures === queries.length) throw lastError;
  return [...byId.values()];
}
```

```ts
import { XMLParser } from 'fast-xml-parser';
import type { NewsItem } from './types';

/**
 * Keyword news from Google News RSS (Belgian Dutch edition, last 7 days).
 *
 * Yahoo's search is weak for free keywords (weeks-old hits), so keywords go here.
 * Each item has a title (suffixed " - <source>"), a news.google.com redirect link, a
 * guid, a pubDate and a <source>; there is no article body.
 */

const MAX_ITEMS = 20;

const parser = new XMLParser({
  // A title like "2026" must stay a string. Attributes (guid isPermaLink, source url) are
  // dropped by default, which turns <guid>/<source> into plain text.
  parseTagValue: false,
  // A channel with one item must still parse to an array.
  isArray: (name) => name === 'item',
});

interface RssItem {
  title?: string;
  link?: string;
  guid?: string;
  pubDate?: string;
  source?: string;
}

export function googleNewsUrl(keyword: string): string {
  const q = encodeURIComponent(`${keyword} when:7d`);
  return `https://news.google.com/rss/search?q=${q}&hl=nl&gl=BE&ceid=BE:nl`;
}

function normalizeTitle(title: string): string {
  return title.toLowerCase().replace(/\s+/g, ' ').trim();
}

export function parseGoogleNewsRss(xml: string): NewsItem[] {
  // A consent wall or error page answers 200 with HTML: that is a failure, not "no news".
  let doc: { rss?: { channel?: { item?: RssItem[] } | string } };
  try {
    doc = parser.parse(xml);
  } catch {
    throw new Error('Not an RSS document');
  }
  if (!doc?.rss) throw new Error('Not an RSS document');
  const channel = typeof doc.rss.channel === 'object' ? doc.rss.channel : undefined;

  const items: NewsItem[] = [];
  for (const it of channel?.item ?? []) {
    if (!it.guid || !it.title || !it.link || !it.pubDate) continue;
    const published = new Date(it.pubDate);
    if (isNaN(published.getTime())) continue;
    const publisher = it.source?.trim() || null;
    const suffix = publisher ? ` - ${publisher}` : null;
    const title = suffix && it.title.endsWith(suffix) ? it.title.slice(0, -suffix.length) : it.title;
    items.push({
      id: it.guid,
      title: title.trim(),
      publisher,
      url: it.link,
      published_at: published.toISOString(),
      source: 'google',
    });
  }

  // Collapse identical titles to the earliest copy, then keep the newest MAX_ITEMS.
  items.sort((a, b) => a.published_at.localeCompare(b.published_at));
  const seen = new Set<string>();
  const unique = items.filter((item) => {
    const key = normalizeTitle(item.title);
    if (seen.has(key)) return false;
    seen.add(key);
    return true;
  });
  return unique.reverse().slice(0, MAX_ITEMS);
}

export async function fetchKeywordNews(keyword: string): Promise<NewsItem[]> {
  const res = await fetch(googleNewsUrl(keyword));
  if (!res.ok) throw new Error(`Google News answered ${res.status}`);
  return parseGoogleNewsRss(await res.text());
}
```

```ts
import { db } from '../db';
import type { NewsTopicKind } from '../helpers/constants';
import type { NewsItem } from '../services/providers/types';

/** A followed subject as stored on article links: a ticker symbol or a keyword. */
export interface TopicRef {
  kind: NewsTopicKind;
  value: string;
}

export interface NewsTopicRow extends TopicRef {
  id: number;
  created_at: string;
}

export interface NewsArticleRow extends NewsItem {
  fetched_at: string;
}

export interface NewsArticleWithTopics extends NewsArticleRow {
  topics: TopicRef[];
}

export function topicKey(t: TopicRef): string {
  return `${t.kind}:${t.value}`;
}

export function listNewsTopics(): NewsTopicRow[] {
  return db.prepare(`SELECT * FROM news_topics ORDER BY id`).all() as NewsTopicRow[];
}

export function getNewsTopic(id: number): NewsTopicRow | null {
  return (db.prepare(`SELECT * FROM news_topics WHERE id = ?`).get(id) as NewsTopicRow | undefined) ?? null;
}

/** Case-insensitive on value (the column is COLLATE NOCASE). */
export function findNewsTopic(t: TopicRef): NewsTopicRow | null {
  return (
    (db.prepare(`SELECT * FROM news_topics WHERE kind = ? AND value = ?`).get(t.kind, t.value) as
      | NewsTopicRow
      | undefined) ?? null
  );
}

export function insertNewsTopic(t: TopicRef): NewsTopicRow {
  const info = db.prepare(`INSERT INTO news_topics (kind, value) VALUES (?, ?)`).run(t.kind, t.value);
  return getNewsTopic(Number(info.lastInsertRowid))!;
}

export function deleteNewsTopic(id: number): boolean {
  return db.prepare(`DELETE FROM news_topics WHERE id = ?`).run(id).changes > 0;
}

/**
 * Store one topic's articles. An article keeps its first fetched_at (that is what "new"
 * is measured against) and gets this topic's badge at most once.
 */
export function saveArticles(topic: TopicRef, items: NewsItem[], fetchedAt: string): void {
  const insertArticle = db.prepare(`
    INSERT OR IGNORE INTO news_articles (id, title, publisher, url, published_at, source, fetched_at)
    VALUES (@id, @title, @publisher, @url, @published_at, @source, @fetched_at)
  `);
  const insertLink = db.prepare(
    `INSERT OR IGNORE INTO news_article_topics (article_id, kind, value) VALUES (?, ?, ?)`,
  );
  db.transaction(() => {
    for (const item of items) {
      insertArticle.run({ ...item, fetched_at: fetchedAt });
      insertLink.run(item.id, topic.kind, topic.value);
    }
  })();
}

/** Delete articles published before the cutoff; their links go with them (ON DELETE CASCADE). */
export function pruneArticles(olderThan: string): number {
  return db.prepare(`DELETE FROM news_articles WHERE published_at < ?`).run(olderThan).changes;
}

// Matches a link against a JSON array of topicKey()s. kind never contains ':', so the key is unambiguous.
const FOLLOWED = `t.kind || ':' || t.value IN (SELECT value FROM json_each(?))`;

/** Articles linked to at least one of `topics`, newest first, with only those topics as badges. */
export function listArticlesFor(topics: TopicRef[]): NewsArticleWithTopics[] {
  const rows = db
    .prepare(`
      SELECT a.*, t.kind AS topic_kind, t.value AS topic_value
      FROM news_articles a
      JOIN news_article_topics t ON t.article_id = a.id
      WHERE ${FOLLOWED}
      ORDER BY a.published_at DESC, a.id, t.kind, t.value
    `)
    .all(JSON.stringify(topics.map(topicKey))) as (NewsArticleRow & {
    topic_kind: NewsTopicKind;
    topic_value: string;
  })[];

  const byId = new Map<string, NewsArticleWithTopics>();
  for (const { topic_kind, topic_value, ...article } of rows) {
    let entry = byId.get(article.id);
    if (!entry) {
      entry = { ...article, topics: [] };
      byId.set(article.id, entry);
    }
    entry.topics.push({ kind: topic_kind, value: topic_value });
  }
  return [...byId.values()];
}

/** Distinct articles about `topics` first fetched after `since` — the navbar badge. */
export function countFetchedAfter(topics: TopicRef[], since: string): number {
  const row = db
    .prepare(`
      SELECT COUNT(DISTINCT a.id) AS n
      FROM news_articles a
      JOIN news_article_topics t ON t.article_id = a.id
      WHERE a.fetched_at > ? AND ${FOLLOWED}
    `)
    .get(since, JSON.stringify(topics.map(topicKey))) as { n: number };
  return row.n;
}
```

```ts
import { fetchTickerNews } from './providers/yahooNews';
import { fetchKeywordNews } from './providers/googleNews';
import type { NewsItem } from './providers/types';
import { recordFailure, recordSuccess } from './providerHealth';
import { openTickers } from './positionsCalc';
import { getTicker } from '../queries/prices';
import { listNewsTopics, pruneArticles, saveArticles, topicKey, type TopicRef } from '../queries/news';
import { logger } from '../helpers/logger';
import { errorMessage } from '../helpers/errors';
import {
  NEWS_REFRESH_INTERVAL_MS,
  NEWS_RETENTION_DAYS,
  NEWS_RETRY_AFTER_FAILURE_MS,
} from '../helpers/constants';

/**
 * News feed orchestration (issue #11).
 *
 * Followed topics = open positions (derived) ∪ news_topics (watchlist + keywords). A round
 * fetches every topic sequentially, stores articles + badges, then prunes past retention.
 * There is no timer: the navbar's badge poll calls maybeRefresh(), which starts a round in
 * the background when the last one is stale. The last-refresh time lives in memory only,
 * so every app start fetches straight away.
 */

export type NewsTopicOrigin = 'POSITION' | 'WATCHLIST' | 'KEYWORD';

export interface FollowedTopic extends TopicRef {
  /** news_topics.id; null for a position that isn't also on the watchlist. */
  id: number | null;
  origin: NewsTopicOrigin;
}

export interface NewsStatus {
  last_refresh_at: string | null;
  refreshing: boolean;
  failed_topics: TopicRef[];
}

let now: () => number = Date.now;
let inFlight: Promise<void> | null = null;
let lastRefreshAt: number | null = null;
let lastRoundAllFailed = false;
let failedTopics: TopicRef[] = [];

/** Test hook: drive the refresh thresholds without real time passing. */
export function _setNewsClock(fn: () => number): void {
  now = fn;
}

export function _resetNewsService(): void {
  now = Date.now;
  inFlight = null;
  lastRefreshAt = null;
  lastRoundAllFailed = false;
  failedTopics = [];
}

export function newsNowIso(): string {
  return new Date(now()).toISOString();
}

function retentionCutoff(): string {
  return new Date(now() - NEWS_RETENTION_DAYS * 24 * 60 * 60 * 1000).toISOString();
}

export function followedTopics(): FollowedTopic[] {
  const out = new Map<string, FollowedTopic>();
  for (const symbol of openTickers()) {
    const topic: FollowedTopic = { id: null, kind: 'TICKER', value: symbol, origin: 'POSITION' };
    out.set(topicKey(topic), topic);
  }
  for (const row of listNewsTopics()) {
    const held = out.get(topicKey(row));
    if (held) {
      // Held and on the watchlist: shown as the position, but the watchlist row takes over
      // (and stays removable) once the position is sold.
      held.id = row.id;
      continue;
    }
    out.set(topicKey(row), {
      id: row.id,
      kind: row.kind,
      value: row.value,
      origin: row.kind === 'TICKER' ? 'WATCHLIST' : 'KEYWORD',
    });
  }
  return [...out.values()];
}

/** Log-safe name: a keyword reveals interests and must not leave the machine via Sentry. */
function topicLabel(topic: FollowedTopic): string {
  return topic.kind === 'TICKER' ? topic.value : `keyword #${topic.id ?? '?'}`;
}

function fetchTopic(topic: FollowedTopic): Promise<NewsItem[]> {
  if (topic.kind === 'TICKER') return fetchTickerNews(topic.value, getTicker(topic.value)?.name ?? null);
  return fetchKeywordNews(topic.value);
}

/** Fetch + store one topic. Returns false when its source failed. */
async function ingestTopic(topic: FollowedTopic): Promise<boolean> {
  const provider = topic.kind === 'TICKER' ? 'yahoo' : 'google';
  try {
    const items = await fetchTopic(topic);
    recordSuccess(provider, 'news');
    // Skip stale items up front: inserting then pruning them would re-insert them as
    // "new" every round (Yahoo's name search returns months-old articles).
    const cutoff = retentionCutoff();
    saveArticles(topic, items.filter((i) => i.published_at >= cutoff), newsNowIso());
    return true;
  } catch (err) {
    const message = errorMessage(err);
    logger.warn('news', `fetch failed for ${topicLabel(topic)}: ${message}`);
    recordFailure(provider, 'news', message);
    return false;
  }
}

async function runRefresh(): Promise<void> {
  const topics = followedTopics();
  const failed: TopicRef[] = [];
  // Sequential on purpose: Yahoo rate-limits bursts.
  for (const topic of topics) {
    if (!(await ingestTopic(topic))) failed.push({ kind: topic.kind, value: topic.value });
  }
  pruneArticles(retentionCutoff());
  lastRefreshAt = now();
  failedTopics = failed;
  lastRoundAllFailed = topics.length > 0 && failed.length === topics.length;
}

/** One round at a time: a caller arriving mid-round gets the running round's promise. */
export function refreshNews(): Promise<void> {
  if (!inFlight) {
    inFlight = runRefresh().finally(() => {
      inFlight = null;
    });
  }
  return inFlight;
}

/** Fetch a single topic right after it was followed, so the user sees results at once. */
export async function refreshTopic(topic: FollowedTopic): Promise<void> {
  const ok = await ingestTopic(topic);
  failedTopics = failedTopics.filter((t) => topicKey(t) !== topicKey(topic));
  if (!ok) failedTopics.push({ kind: topic.kind, value: topic.value });
}

/** Start a background round when the last one is stale. Never awaited by callers. */
export function maybeRefresh(): void {
  if (inFlight) return;
  if (lastRefreshAt != null) {
    const wait = lastRoundAllFailed ? NEWS_RETRY_AFTER_FAILURE_MS : NEWS_REFRESH_INTERVAL_MS;
    if (now() - lastRefreshAt < wait) return;
  }
  refreshNews().catch((err) => logger.error('news', `refresh failed: ${errorMessage(err)}`));
}

export function getStatus(): NewsStatus {
  return {
    last_refresh_at: lastRefreshAt != null ? new Date(lastRefreshAt).toISOString() : null,
    refreshing: inFlight != null,
    failed_topics: failedTopics,
  };
}
```

```ts
import { Router } from 'express';
import { z } from 'zod';
import {
  followedTopics,
  getStatus,
  maybeRefresh,
  newsNowIso,
  refreshNews,
  refreshTopic,
} from '../services/newsService';
import {
  countFetchedAfter,
  deleteNewsTopic,
  findNewsTopic,
  insertNewsTopic,
  listArticlesFor,
  topicKey,
} from '../queries/news';
import { fetchQuote } from '../services/marketData';
import { getSetting, upsertSetting } from '../helpers/settings';
import { SETTING_KEYS } from '../helpers/constants';
import { errorMessage } from '../helpers/errors';
import { logger } from '../helpers/logger';

const router = Router();

const EPOCH = new Date(0).toISOString();

const topicSchema = z.discriminatedUnion('kind', [
  z.object({
    kind: z.literal('TICKER'),
    value: z.string().trim().toUpperCase().regex(/^[A-Z0-9.^=\-]{1,20}$/, 'Ongeldig tickersymbool'),
  }),
  z.object({
    kind: z.literal('KEYWORD'),
    value: z.string().trim().min(2).max(60),
  }),
]);

const seenSchema = z.object({ seen_at: z.string().datetime() });

function lastSeen(): string {
  return getSetting(SETTING_KEYS.NEWS_LAST_SEEN) ?? EPOCH;
}

/**
 * The tab's payload. as_of is taken *before* reading, and the client echoes it back to
 * POST /seen: an article landing in between then stays "new" rather than being marked
 * seen without ever having been shown.
 */
function newsPayload() {
  const asOf = newsNowIso();
  const seen = lastSeen();
  const topics = followedTopics();
  const articles = listArticlesFor(topics).map(({ fetched_at, ...article }) => ({
    ...article,
    is_new: fetched_at > seen,
  }));
  return { articles, topics, status: getStatus(), as_of: asOf };
}

router.get('/', (_req, res) => {
  try {
    res.json(newsPayload());
  } catch (err) {
    res.status(500).json({ error: errorMessage(err) });
  }
});

// The navbar polls this; it is also what keeps the background refresh going.
router.get('/unread', (_req, res) => {
  try {
    maybeRefresh();
    res.json({ count: countFetchedAfter(followedTopics(), lastSeen()), refreshing: getStatus().refreshing });
  } catch (err) {
    res.status(500).json({ error: errorMessage(err) });
  }
});

router.post('/seen', (req, res) => {
  const parsed = seenSchema.safeParse(req.body);
  if (!parsed.success) {
    return res.status(400).json({ error: 'Invalid seen_at', issues: parsed.error.issues });
  }
  const seenAt = new Date(parsed.data.seen_at).toISOString();
  if (seenAt > newsNowIso()) return res.status(400).json({ error: 'seen_at ligt in de toekomst' });
  // Never move backwards: a late, older echo must not bring back "new" labels.
  if (seenAt > lastSeen()) upsertSetting(SETTING_KEYS.NEWS_LAST_SEEN, seenAt);
  res.status(204).end();
});

router.post('/refresh', async (_req, res) => {
  try {
    await refreshNews();
    res.json(newsPayload());
  } catch (err) {
    res.status(500).json({ error: errorMessage(err) });
  }
});

router.post('/topics', async (req, res) => {
  const parsed = topicSchema.safeParse(req.body);
  if (!parsed.success) {
    return res.status(400).json({ error: 'Ongeldig onderwerp', issues: parsed.error.issues });
  }
  try {
    if (findNewsTopic(parsed.data)) return res.status(409).json({ error: 'Dit onderwerp volg je al' });
    const row = insertNewsTopic(parsed.data);
    if (row.kind === 'TICKER') {
      // Fill the tickers cache first so the news search can also query by company name.
      await fetchQuote(row.value).catch((err) =>
        logger.warn('news', `quote warm-up for ${row.value} failed: ${errorMessage(err)}`),
      );
    }
    const topic = followedTopics().find((t) => topicKey(t) === topicKey(row))!;
    // A failed first fetch shows up in status.failed_topics; the topic is still followed.
    await refreshTopic(topic);
    res.status(201).json({ topic });
  } catch (err) {
    res.status(500).json({ error: errorMessage(err) });
  }
});

router.delete('/topics/:id', (req, res) => {
  try {
    if (!deleteNewsTopic(parseInt(req.params.id, 10))) return res.status(404).json({ error: 'Not found' });
    res.status(204).end();
  } catch (err) {
    res.status(500).json({ error: errorMessage(err) });
  }
});

export default router;
```

```ts
import type { NewsArticle, NewsTopicRef } from '../models';

/** Sleutel van een onderwerp; kind erbij zodat ticker "NVDA" ≠ trefwoord "NVDA". */
export function topicKey(t: NewsTopicRef): string {
  return `${t.kind}:${t.value}`;
}

/** Artikels voor één chip; `null` is "Alles". */
export function filterArticles(articles: NewsArticle[], topic: NewsTopicRef | null): NewsArticle[] {
  if (!topic) return articles;
  const key = topicKey(topic);
  return articles.filter(a => a.topics.some(t => topicKey(t) === key));
}

/** Aantal artikels per chip (sleutel = topicKey), in de volgorde van `topics`; 0 als er geen zijn. */
export function chipCounts(articles: NewsArticle[], topics: NewsTopicRef[]): Map<string, number> {
  const counts = new Map<string, number>(topics.map(t => [topicKey(t), 0]));
  for (const a of articles) {
    for (const t of a.topics) {
      const key = topicKey(t);
      const n = counts.get(key);
      if (n !== undefined) counts.set(key, n + 1);
    }
  }
  return counts;
}
```

```ts
const RELATIVE = new Intl.RelativeTimeFormat(LOCALE, { numeric: 'auto' });

/**
 * Hoe lang geleden: "zonet", "5 minuten geleden", "2 uur geleden", "gisteren".
 * Vanaf 24 uur telt het kalenderdagen; na 7 dagen wordt het een gewone datum.
 */
export function formatRelativeTime(iso: string | null | undefined, now: Date = new Date()): string {
  if (!iso) return '—';
  const d = new Date(iso);
  if (isNaN(d.getTime())) return iso;
  const diff = now.getTime() - d.getTime();
  if (diff < 60_000) return 'zonet';
  if (diff < 3_600_000) return RELATIVE.format(-Math.floor(diff / 60_000), 'minute');
  if (diff < 86_400_000) return RELATIVE.format(-Math.floor(diff / 3_600_000), 'hour');
  const startOfDay = (x: Date) => new Date(x.getFullYear(), x.getMonth(), x.getDate()).getTime();
  const days = Math.round((startOfDay(now) - startOfDay(d)) / 86_400_000);
  if (days > 7) return formatDate(iso);
  return RELATIVE.format(-days, 'day');
}
```

```ts
import { Injectable, inject, signal } from '@angular/core';
import { EMPTY, timer } from 'rxjs';
import { catchError, switchMap } from 'rxjs/operators';
import { ApiService } from './api.service';

export const NEWS_POLL_MS = 120_000;

/**
 * Teller van nieuwe artikels voor de navbar. De poll houdt ook de achtergrondophaling op de
 * backend gaande: /news/unread start een nieuwe ronde als de vorige te oud is.
 */
@Injectable({ providedIn: 'root' })
export class NewsBadgeService {
  private api = inject(ApiService);

  readonly unread = signal(0);

  constructor() {
    timer(0, NEWS_POLL_MS)

        // hele stream, en dan pollt de badge nooit meer.

      .subscribe(r => this.unread.set(r.count));
  }

  /** Na een bezoek aan de Nieuws-tab: alles is gezien. */
  clear(): void {
    this.unread.set(0);
  }
}
```

```ts
/**

@Component({

      <input

                <span class="fw-bold">{{ r.symbol }}</span>
                <span class="text-muted small ms-2">{{ r.name }}</span>
                <span class="text-muted small ms-2">{{ r.exchange }}</span>
              </button>
            </li>
          }
        </ul>
      }
    </div>
  `,
})
export class TickerSearchComponent {
  private api = inject(ApiService);
  private term$ = new Subject<string>();

  readonly placeholder = input('bv. AAPL');
  readonly picked = output<string>();

  term = signal('');
  results = signal<TickerSearchResult[]>([]);
  showResults = signal(false);

  constructor() {
    this.term$
      .pipe(
        debounceTime(250),
        distinctUntilChanged(),
        // Fout binnen de switchMap opvangen, anders stopt de autocomplete na één fout.
        switchMap(t => this.api.searchTicker(t).pipe(catchError(() => of([] as TickerSearchResult[])))),
        takeUntilDestroyed(),
      )
      .subscribe(r => this.results.set(r));
  }

  onInput(value: string): void {
    this.term.set(value);
    if (value.trim()) {
      this.term$.next(value.trim());
      this.showResults.set(true);
    } else {
      this.results.set([]);
    }
  }

  hideResultsSoon(): void {
    setTimeout(() => this.showResults.set(false), 200);
  }

  pick(symbol: string): void {
    this.term.set('');
    this.results.set([]);
    this.showResults.set(false);
    this.picked.emit(symbol.toUpperCase());
  }

  submitTyped(event: Event): void {
    event.preventDefault();
    const symbol = this.term().trim();
    if (symbol) this.pick(symbol);
  }
}
```

```ts
import { ApiService } from '../../services/api.service';
import { NewsBadgeService } from '../../services/news-badge.service';
import { TickerSearchComponent } from '../../shared/ticker-search/ticker-search.component';
import { chipCounts, filterArticles, topicKey } from '../../utils/news-filter';
import { formatDateTime, formatRelativeTime } from '../../utils/format';
import type {
  NewsArticle,
  NewsResponse,
  NewsTopic,
  NewsTopicKind,
  NewsTopicOrigin,
  NewsTopicRef,
} from '../../models';

const ORIGIN_ICONS: Record<NewsTopicOrigin, string> = {
  POSITION: 'bi-briefcase',
  WATCHLIST: 'bi-eye',
  KEYWORD: 'bi-search',
};

@Component({
  selector: 'app-news',
  standalone: true,
  imports: [TickerSearchComponent],
  templateUrl: './news.component.html',
})
export class NewsComponent implements OnInit {
  private api = inject(ApiService);
  private badge = inject(NewsBadgeService);

  /**
   * Artikels die tijdens dit bezoek als nieuw binnenkwamen. De server markeert ze meteen als
   * gezien, dus na ⟳ zou hun label anders verdwijnen; zo blijft het tot je de tab verlaat.
   */
  private visitNew = new Set<string>();

  data = signal<NewsResponse | null>(null);
  filter = signal<NewsTopicRef | null>(null);
  loading = signal(true);
  refreshing = signal(false);
  error = signal<string | null>(null);

  showAdd = signal(false);
  addKind = signal<NewsTopicKind>('TICKER');
  keyword = signal('');
  adding = signal(false);
  addError = signal<string | null>(null);

  readonly articles = computed(() => filterArticles(this.data()?.articles ?? [], this.filter()));
  readonly counts = computed(() => chipCounts(this.data()?.articles ?? [], this.data()?.topics ?? []));
  readonly failedLabel = computed(() =>
    (this.data()?.status.failed_topics ?? []).map(t => t.value).join(', '),
  );

  readonly topicKey = topicKey;
  readonly formatRelativeTime = formatRelativeTime;
  readonly formatDateTime = formatDateTime;

  ngOnInit(): void {
    this.load();
  }

  load(): void {
    this.api.getNews().subscribe({
      next: r => this.show(r),
      error: err => {
        this.loading.set(false);
        this.error.set(err?.error?.error ?? 'Nieuws ophalen mislukt');
      },
    });
  }

  /** Geforceerde ronde; sluit aan bij een ronde die al loopt. */
  refresh(): void {
    this.refreshing.set(true);
    this.api.refreshNews().subscribe({
      next: r => {
        this.refreshing.set(false);
        this.show(r);
      },
      error: err => {
        this.refreshing.set(false);
        this.error.set(err?.error?.error ?? 'Vernieuwen mislukt');
      },
    });
  }

  isNew(a: NewsArticle): boolean {
    return a.is_new || this.visitNew.has(a.id);
  }

  isActive(t: NewsTopicRef): boolean {
    const f = this.filter();
    return f != null && topicKey(f) === topicKey(t);
  }

  originIcon(origin: NewsTopicOrigin): string {
    return ORIGIN_ICONS[origin];
  }

  addTopic(kind: NewsTopicKind, value: string): void {
    const v = value.trim();
    if (!v || this.adding()) return;
    this.adding.set(true);
    this.addError.set(null);
    this.api.addNewsTopic({ kind, value: v }).subscribe({
      next: () => {
        this.adding.set(false);
        this.showAdd.set(false);
        this.keyword.set('');
        this.load();
      },
      error: err => {
        this.adding.set(false);
        this.addError.set(err?.error?.error ?? 'Volgen mislukt');
      },
    });
  }

  removeTopic(t: NewsTopic): void {
    if (t.id == null) return;
    this.api.deleteNewsTopic(t.id).subscribe({
      next: () => this.load(),
      error: err => this.error.set(err?.error?.error ?? 'Verwijderen mislukt'),
    });
  }

  /** Toon een antwoord en meld het als gezien; de badge gaat dan naar 0. */
  private show(r: NewsResponse): void {
    for (const a of r.articles) if (a.is_new) this.visitNew.add(a.id);
    const f = this.filter();
    if (f && !r.topics.some(t => topicKey(t) === topicKey(f))) this.filter.set(null);
    this.data.set(r);
    this.loading.set(false);
    this.error.set(null);
    this.api.markNewsSeen(r.as_of).subscribe({ next: () => this.badge.clear(), error: () => {} });
    // Loopt er al een achtergrondronde (bv. net na het opstarten van de app)? Sluit erbij aan,
    // anders blijft de lijst leeg tot je zelf vernieuwt.
    if (r.status.refreshing && !this.refreshing()) this.refresh();
  }
}
```

```markdown
### News (newsService.ts + providers/yahooNews.ts, googleNews.ts)

- **Followed topics** = open positions (derived via `openTickers()`, never stored) ∪ `news_topics`
```
